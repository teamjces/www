PCなんて今あるんだっけ、という話は置いといて

GRUBで起動イメージを作って遊ぼう。CDやDVDに焼いたりUSBメモリでもいいぞ
いまや多くの人にとって計算機といえばスマートフォンであり、「PCってまだ現役なの？」と感じる人がいても不思議ではない。実際、文章を書く、動画を見る、SNSをする、買い物をする──そういう日常用途ならスマホで十分な場面も多い。

しかし、PCにはまだひとつ決定的な文化が残っている。
起動していない状態の機械を、自分の好きなソフトウェアで目覚めさせる自由である。

その入口として、今日は GRUB を使って遊んでみよう。

---

GRUBとは何か

GNU GRUB はブートローダである。
電源投入直後、OSの前に立ち上がり、どのカーネルを起動するか、どのOSを起こすか、何を読み込むかを決めるソフトだ。

普通の人には黒い画面にしか見えないが、見方を変えればこれは 最初に動くプログラム環境 でもある。

つまり、

・メニューを出せる
・ファイルを読める
・カーネルを起動できる
・initrdを渡せる
・スクリプト的なこともできる

という、なかなか面白い世界だ。

---

何を作るのか

今回はこういう遊びをする。

GRUB入りのISOイメージを作る

・CD/DVDに焼く（まだ持ってるなら）
・USBメモリに書き込む
・実機や仮想マシンで起動する

要するに、

> 自分で作った「起動するメディア」

を作るわけだ。

これは昔ながらのPC文化の中でも、かなり味わい深い遊びである。

---

最小構成でやってみる

Linux環境で GRUB が入っているとして、作業ディレクトリを作る。
mkdir -p iso/boot/grub
設定ファイルを書く。
nano iso/boot/grub/grub.cfg
内容：
set timeout=5 set default=0 menuentry "Hello GRUB" { echo "Hello, world." sleep 5 } menuentry "Reboot" { reboot } menuentry "Poweroff" { halt }
これだけでもう起動メニューになる。

---

ISO化する
grub-mkrescue -o myboot.iso iso/
これで myboot.iso ができる。

このISOはそのまま仮想環境で起動できる。

たとえば QEMU なら：
qemu-system-x86_64 -cdrom myboot.iso
---

CD/DVDに焼く

光学ドライブがあるなら今でも焼ける。
wodim dev=/dev/sr0 myboot.iso
あるいはGUIライティングソフトでもいい。

令和に自作ブートCDを焼く。
この無意味さが素晴らしい。

---

USBメモリに入れる

中身を全部消してよければ：
sudo dd if=myboot.iso of=/dev/sdX bs=4M status=progress sync
※ /dev/sdX はUSBメモリ本体。間違えると泣く。

これでUSB起動メディアになる場合が多い。

---

さらに面白くするには

Linuxカーネルを入れる
menuentry "Tiny Linux" { linux /boot/vmlinuz root=/dev/ram0 initrd /boot/initrd.img }
自作レスキュー環境や実験環境になる。

---

壁紙を出す

GRUBはテーマも使える。
起動直後から妙に凝った画面にできる。

---

自分のメッセージを刻む
echo "This machine belongs to TeamJCES."
起動前に名乗るコンピュータ。悪くない。

---

なぜ今こんな遊びをするのか

スマホ時代になると、多くの機械は「既に誰かが決めた状態」で渡される。
起動順序も、最低層の制御も、利用者には見えない。

だがPCにはまだ、

・電源を入れた瞬間から触れる
・自分のメディアで起こせる
・OSの前段階から弄れる

という文化が残っている。

それは単なる懐古趣味ではなく、
計算機を自分のものとして扱う感覚 に近い。

---

結び

PCなんて今あるんだっけ、という時代でも、GRUBで起動イメージを作って遊ぶ価値はある。

CDでもDVDでもUSBでもいい。
何なら仮想マシンだけでもいい。

自分で作ったメニューが現れ、そこから機械が目覚める。

その瞬間、コンピュータはまだ少しだけ、こちら側のものだ。
